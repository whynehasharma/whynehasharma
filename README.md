**Python • FastAPI • UDP • WebSockets • React • TypeScript • Recharts**

- Processes telemetry using a Python backend
- Streams real-time updates using WebSockets
- Visualizes live telemetry signals and UAV trajectory
- Displays connection and system status
- Built a responsive Ground Control Station-style interface
